## 📚 Company Knowledge Base Chatbot — RAG

A **Retrieval-Augmented Generation** chatbot that allows users to
ask questions about company documents using natural language.

### What it does

- 📄 Processes PDF and text documents
- ✂️ Splits documents into chunks
- 🧠 Generates embeddings
- 🔎 Performs semantic similarity search
- 🗃️ Stores embeddings in a vector database
- 💬 Generates answers using an LLM

**Tech:** Python • LangChain • RAG • Embeddings • FAISS/ChromaDB • LLM

🔗 [View Project](https://github.com/yashsharma006/company-chatbot-rag.git)
